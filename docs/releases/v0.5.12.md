# codex-peer v0.5.12

A version-alignment release. Its runtime is unchanged from v0.5.9, and its version now matches core v0.5.12. It requires Sessionbus v0.5.9 or newer (daemon and hub) and still pins the Sessionbus Go SDK `v0.5.9`; it does not include Go SDK v0.5.12. Native Codex is installed separately and is not pinned.

`scripts/install-codex.sh` installs the latest stable release by default, so it now installs v0.5.12. Upgrading from v0.5.9 changes no behaviour and needs no daemon, hub or lane-row change.

## Changes since v0.5.9
- **Versions:**
  - `RELEASE_VERSION` is 0.5.12;
  - the Codex plugin source version (`codex/marketplace/codex/.codex-plugin/plugin.json`) is `0.5.12-codex.0`;
  - packaged archives carry `0.5.12-codex.g<revision>`, as before.
- **Third-party notices:** the packaged `THIRD-PARTY-NOTICES.txt` now matches the dependencies actually built in: Sessionbus Go SDK v0.5.9, peer-common and BurntSushi/toml v1.6.0. In v0.5.9 it named an older SDK revision and omitted the other two.
- **Contributor rules:** the repository now has contributor rules (`AGENTS.md`).
- No runtime, installer, dependency or workflow change.

## Evidence
No new live/native acceptance was run for this release; its runtime is v0.5.9's.
